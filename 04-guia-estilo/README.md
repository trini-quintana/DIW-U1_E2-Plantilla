# Guía de estilo

Guarda aquí la guía de estilo en PDF con el nombre `E2_GuiaEstilo_NombreApellido.pdf`.

Debe tener los nueve apartados: descripción del sitio, voz y tono, paleta (hexadecimal, uso y ratio de contraste de cada par texto/fondo), tipografías y dónde se usan, iconografía, imágenes, elementos interactivos con sus estados, espaciado, y rejilla con puntos de ruptura.
